- Добавлен только файл оформления `assets/css/intro-integration.css`: усилена читаемость текста и изменена типографика. Секции основного сайта, фотографии, фон, содержание и RSVP сохранены из исходного архива.
- Максимальная ширина 430 px, на большом мониторе приглашение остаётся по центру.
- Добавлены «Пропустить» и fallback при сбое видео, адаптация к настройке «уменьшить движение».

## Как открыть

Распаковать архив. В папке с `index.html` выполнить:

```bash
python -m http.server 8080
```

Открыть в браузере `http://localhost:8080`.

Для публикации GitHub Pages: загрузить файлы из корня папки в репозиторий, затем Settings → Pages → Deploy from a branch → main / (root).

Внимание: GitHub Pages публично размещает фотографии, телефон RSVP и банковские реквизиты, содержащиеся в исходном сайте.
