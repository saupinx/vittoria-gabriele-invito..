# Версия: новые фотографии Dress Code

Обновлена только секция Dress Code: переключатель PER LEI / PER LUI показывает два исходных изображения заказчика. По нажатию на фото оно открывается в модальном окне с возможностью закрыть кнопкой ×, касанием затемнения или Esc.

Сохранены исходные MP4 открытия конверта, первый экран, фон, 4K фотография пары, RSVP, остальные секции и тексты.

Для проверки распакуйте архив и запустите в этой папке `python -m http.server 8000`, затем откройте `http://localhost:8000` на устройстве/эмуляторе.
